# HTML/CSS Prototypes

A collection of modern, responsive HTML/CSS prototypes for web design inspiration and rapid prototyping.

## 🎨 Prototypes Included

### 1. Landing Page
A modern landing page featuring:
- Hero section with gradient background
- Features grid with hover effects
- Call-to-action sections
- Responsive navigation
- Footer with multiple sections

### 2. Analytics Dashboard
A comprehensive dashboard prototype with:
- Sidebar navigation
- Stats cards with metrics
- Interactive charts (bar chart and donut chart)
- Recent activity feed
- Fully responsive layout

### 3. Product Cards
An e-commerce product grid featuring:
- Responsive product card layout
- Product badges (New, Sale, Bestseller)
- Star ratings and reviews
- Add to cart functionality
- Filter and sort options
- Shopping cart indicator

## 🚀 Features

- **Fully Responsive**: All prototypes work seamlessly on desktop, tablet, and mobile devices
- **Modern Design**: Clean, contemporary UI with gradients and smooth transitions
- **CSS-Only**: No JavaScript required for core functionality
- **Easy to Customize**: Well-organized CSS with CSS custom properties (variables)
- **Production-Ready**: Clean, semantic HTML structure

## 🎯 How to Use

### Local Development
1. Clone the repository
2. Open `index.html` in your browser
3. Navigate to any prototype from the gallery

### GitHub Pages (Public Viewing)
To make these prototypes publicly accessible:

1. Go to your GitHub repository settings
2. Navigate to "Pages" in the sidebar
3. Under "Source", select the branch: `claude/html-css-prototypes-01RwvM5iNxH6qznKa5kDYBYM`
4. Click "Save"
5. Your prototypes will be available at: `https://larionovaleksandr.github.io/limitless-prototypes/`

## 🎨 Customization

All prototypes use CSS custom properties for easy theming:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --dark-bg: #0f172a;
    --light-bg: #f8fafc;
    --text-dark: #0f172a;
    --text-light: #64748b;
}
```

Simply modify these values in the respective CSS files to change colors throughout the prototype.
